# shorts-cutter: выбор API

Почему модуль устроен именно так, какие API рассматривались и сколько это стоит. Как пользоваться — в
[README.md](../README.md).

## Можно ли сделать на OpenAI

**Да, но не в виде «загрузил видео → получил шорты».** Проверено по документации на 26.10.2026.

1. **OpenAI API не принимает видео.** GPT-5.x/6.x принимают текст и изображения, Sora — генерация видео,
   не анализ. Поэтому схема такая: ffmpeg достаёт аудио → OpenAI транскрибирует → GPT выбирает моменты
   по тексту → ffmpeg режет и вшивает субтитры. Резка, 9:16 и субтитры — это ffmpeg на нашей стороне,
   не AI.
2. **Модель «не видит» картинку**, выбирает только по речи. Для подкастов, интервью, лекций, вебинаров
   этого достаточно. Моменты без слов (реакция, демонстрация, спорт) она пропустит.
3. **Главный риск — таймкоды слов.** Без них нельзя ни синхронизировать субтитры, ни резать точно по
   словам. В OpenAI их отдаёт только `whisper-1`, а его **отключают 26.02.2027**. Рекомендуемая сейчас
   `gpt-transcribe` возвращает только текст. До февраля транскрипцию нужно перевести на другой API.
4. Лимит 25 МБ на файл — модуль сам режет аудио на куски по 20 минут.

## Что использовать

| Задача | Вариант | Цена (1 ч видео) | Комментарий |
|---|---|---|---|
| Транскрипция | OpenAI `whisper-1` | $0.36 | Таймкоды слов, но отключение 26.02.2027 |
| Транскрипция | **ElevenLabs Scribe v2** | **$0.22** | Таймкоды слов, русский и казахский, файл до 5 ГБ без нарезки |
| Выбор моментов | **OpenAI `gpt-6.1-sol`** | ~$0.05–0.10 | По тексту транскрипта, structured output |
| Выбор моментов | Google Gemini 3.8 Flash | ~$0.27 (low res), с 01.01.2027 ×2 | Принимает видео целиком и видит картинку; File API до 20 ГБ, ~1 ч в high / ~3 ч в low res |
| Всё под ключ | Klap API | ~$8.4 за 10 шортов | $0.44 за видео + $0.32 за шорт + $0.48 за экспорт |
| Всё под ключ | Vizard API | подписка, API на платных планах | Длину задать точно нельзя: пресеты «<30 с», «30–60 с» |
| Всё под ключ | OpusClip | API только на тарифе Business | Цена не опубликована |

**Рекомендация:**

- Сейчас: OpenAI `whisper-1` + `gpt-6.1-sol` — всё работает на одном ключе OpenAI. Это значение по умолчанию.
- До февраля 2027: переключить транскрипцию на ElevenLabs Scribe (`SHORTS_TRANSCRIBER=elevenlabs`, уже
  поддержано). Выходит дешевле `whisper-1`, и нарезка не нужна.
- Если важна картинка, а не только речь, — добавить селектор на Gemini, который смотрит видео целиком.
  Субтитры всё равно строятся по таймкодам слов из транскрипции.
- Готовые сервисы дают быстрый старт, но в ~20 раз дороже своей сборки (~$0.3–0.45 за час видео + CPU
  на ffmpeg) и почти не дают управлять результатом.

## Как работает

```
video.mp4
  │ ffmpeg: аудио mono 16 kHz mp3 (~14 МБ/час)
  ▼
транскрипция: whisper-1 | ElevenLabs Scribe ──▶ слова с таймкодами ──▶ transcript.json (кэш)
  │ предложения "[12.3-17.8] текст"
  ▼
выбор моментов: gpt-6.1-sol, structured output ──▶ start/end, заголовок, хук, оценка 1–10 ──▶ clips.json (кэш)
  │ привязка к границам слов, 15–30 с, без пересечений, лучшие первыми
  ▼
ffmpeg: вырезка → 9:16 (crop | blur) → субтитры ASS по 1–3 слова ──▶ clip_NN.mp4 + clip_NN.srt
```

## Встраивание в Content Factory

Стек тот же, что в [PLAN.md](../../PLAN.md): Python 3.12, `uv`, `ruff`, `pytest`, OpenAI Responses API со
Structured Outputs. Модуль — библиотека плюс CLI. Фабрика вызывает `shorts_cutter.pipeline.run(...)` из своего
worker, а готовые клипы отправляет на тот же Telegram-ревью, что и статьи: карточка с видео, заголовком и
хуком, кнопки ✅ / ❌. Рендер ffmpeg загружает CPU, поэтому на общем VPS клипы лучше рендерить по одному.

## Ограничения и что дальше

- Путь через OpenAI (`whisper-1` + `gpt-6.1-sol`) проверен на реальном 13-минутном видео на английском.
  ElevenLabs и качество на казахском ещё не проверялись.
- `crop` берёт центр кадра и не следит за говорящим. Для «говорящих голов» нужен трекинг лица (MediaPipe).
- `whisper-1`: слово на стыке 20-минутных кусков может разрезаться. У ElevenLabs нарезки нет.
- Клип, который после привязки к словам короче минимума, отбрасывается, поэтому шортов может быть меньше `--count`.
- Пока не подключён к worker и Telegram-боту фабрики (см. раздел выше).
- Селектор на Gemini для моментов, которые важны визуально.
